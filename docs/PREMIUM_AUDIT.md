# 프리미엄 혜택 감사 (2026-08-19)

배포 직전에 "프리미엄 화면이 파는 6가지가 실제로 있는가"를 코드로 확인했다.
같은 종류의 문제를 이미 두 번(7일 무료체험, 자동갱신) 잡았기 때문에 나머지도 의심했다.

## 결과 — 실제로 잠긴 기능이 하나도 없다

| 화면에서 파는 것 | 실제 |
|---|---|
| 🎙️ 가이드 음성 명상 | **이미 무료.** `Breathe.jsx`의 나레이션 토글은 누구나 켠다 |
| 🎚️ 나만의 호흡 패턴 (초 단위 직접 설정) | **없다.** 편집기가 없다. 세션 중 ± 속도 조절만 있고 그것도 무료 |
| 🌿 앰비언트 사운드 라이브러리 (빗소리·숲·파도…) | **이미 무료. 그리고 라이브러리가 아니다** — `ambient.js`는 `kind = 'ocean'` 고정. 파도 하나뿐이고 모닥불은 비활성화 |
| 📊 긴 기간 분석 · 기록 검색 · 갈래별 비교 | **잠긴 게 아니다.** `Journal.jsx`는 기록을 자르지 않는다. 12개가 넘으면 프리미엄으로 가는 **광고 카드**가 하나 뜰 뿐이다 |
| 🤖 AI 수행 코칭 | **없다.** `Premium.jsx` 말고는 코드 어디에도 없다 |
| 🌱 후원 | 사실 |

근거: `grep -rn "isPremium" src` 로 실제 잠금 지점은 세 곳뿐이고,
`grep -n "premium: true" src/pages/Breathe.jsx` 는 **하나도 잡히지 않는다**
(`PATTERNS`·`DURATIONS` 전 항목이 `premium: false`).

## 왜 이렇게 됐나

무료 범위를 넓힌 결정 자체는 근거가 있다 — `PRODUCT_STRATEGY.md` 6-2에
"5분 제한은 제1념처도 못 끝낸다", "프리셋만 잠그면 앞뒤가 안 맞는다"고 적혀 있고 맞는 판단이다.
문제는 **무료로 푼 것을 프리미엄 목록에서 지우지 않았다**는 것이다.
전략 문서에는 "커스텀 패턴을 판다"고 썼는데 그 커스텀 패턴을 만들지 않았다.

## 지금 결제를 열면

39,000원을 받고 **실제로 더 주는 것이 없다.**
전자상거래법 제21조의2(거짓·과장 표시)와 표시광고법 문제이기도 하지만,
그 전에 돈을 낸 사람이 아무것도 못 받는다.

## 선택지

**A. 문구를 실제에 맞춘다** — 팔 것이 사실상 없으므로 결제 자체를 미룬다.
가장 정직하지만 수익 검증이 미뤄진다.

**B. 약속한 것 중 만들 수 있는 것을 만든다**
- 커스텀 패턴 편집기 — 전략 문서가 이미 "이걸 판다"고 정한 것. 반나절
- 앰비언트 여러 종 — 모닥불은 코드가 이미 있고 꺼져 있을 뿐이다. 빗소리·숲 추가. 반나절
- 긴 기간 분석 — 무료를 이번 달로 자르고 그 이상을 프리미엄으로. 반나절
- AI 코칭 — 제일 크다. 나중으로

**C. 지금 무료인 것을 잠근다** — 권하지 않는다.
이미 쓰던 사람에게서 뺏는 것이고, "무료로 열어 신뢰를 얻는다"는 전략과 정면으로 어긋난다.

**추천: B.** 무료 범위는 그대로 두고, 프리미엄 쪽에 실제로 새 가치를 얹는다.
그때까지 프리미엄 화면에서 없는 항목(AI 코칭)은 "준비 중"으로 명확히 표시하거나 지운다.

# 후속 (2026-08-19, 같은 날) — B안 실행 완료

"무료는 그대로 두고 프리미엄에 새 가치를 얹는다"로 결정. 셋 다 만들었다.

| 만든 것 | 무료 | 프리미엄 |
|---|---|---|
| 나만의 호흡 패턴 | 프리셋 5종 + 속도 조절 (그대로) | 들숨·멈춤·날숨을 초 단위로 직접 |
| 배경음 | 파도 (그대로) | 빗소리·숲·모닥불 중 고르기 |
| 되돌아보기 | 기록 전체 열람 · 이번 달 히트맵 (그대로) | 3·6개월·전체 갈래별 비교 + 소감 검색 |

**뺏은 것이 하나도 없다.** 전부 위에 얹었다. 구독이 끝나면 고른 배경음이
파도로 자동으로 돌아가고 소리가 끊기지 않는다(`allowedAmbient`).

혜택 목록에서 뺀 것과 이유
- **가이드 음성** — 원래 무료다(나레이션 토글). 무료 목록으로 옮겼다.
- **광고 없는 공간** — 애초에 광고가 없다. 없는 것을 팔 수 없다.
- **AI 수행 코칭** — 아직 만들지 않았다. 만든 뒤에 적는다.

검증
- 비로그인: 나만의 🔒, 빗소리·숲·모닥불 🔒 — 잠금 확인
- 프리미엄(임시 강제 후 복구): 편집기 동작(4→6초, 합계 16초 갱신), 배경음 4종 해제
- 배경음 4종 모두 예외 없이 그래프 시작, 모르는 값은 파도로 대체
- ⚠️ **소리의 질감 자체는 기계로 확인할 수 없다.** 사람이 직접 들어봐야 한다.
- 375px 가로 넘침 없음
