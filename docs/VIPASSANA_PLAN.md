## 1. 가장 중요한 설계 원칙 — 화면이 호흡을 지시하면 안 된다

| | 아나빠나사띠 | 요가 호흡법 | **위빠사나** |
|---|---|---|---|
| 하는 일 | 호흡을 **관찰** | 호흡을 **조절** | 몸·느낌·마음 현상을 **관찰** |
| 대상 | 호흡 하나 | 호흡 하나 | 지금 일어나는 **모든 현상** |
| 화면의 역할 | 리듬 안내 | 리듬 지시 | **리듬을 지시하면 안 됨** |

**⚠️ 함정:** 요가처럼 "들이쉬기 4초 → 내쉬기 6초" 오브를 그대로 쓰면 사용자가 위빠사나를 **호흡 조절법으로 오해**한다. 위빠사나는 숨을 있는 그대로 두고 그것을 지켜보는 수행이다.

**→ 결정: 오브는 호흡을 지시하지 않는다.** 호흡과 무관한 아주 느린 자율 맥동(8초 주기)만 하고, 화면은 "무엇을 볼지"만 안내한다.

## 2. 학습 콘텐츠 — 사념처를 그대로 단계로

아나빠나사띠 16단계의 4테트라드(몸·느낌·마음·법)와 같은 뼈대라, 두 기능이 자연스럽게 연결된다.

| 단계 | 사념처 | 내용 |
|---|---|---|
| 1단계 · 이해 | — | 위빠사나란 / 사마타와의 차이 / 아나빠나사띠와의 관계 / 삼법인 / **안전 안내** |
| 2단계 · 몸 | 신념처 (kāya) | 호흡 관찰, 몸 훑기, 경행 |
| 3단계 · 느낌 | 수념처 (vedanā) | 좋음·싫음·덤덤함 관찰 |
| 4단계 · 마음 | 심념처 (citta) | 마음 상태 알아차림 |
| 5단계 · 법 | 법념처 (dhamma) | 열린 알아차림, 무상 관찰 |

### 2-1. 개념 콘텐츠 요지

- **위빠사나(vipassanā)** = `vi`(꿰뚫어, 분리하여) + `passanā`(봄) → 있는 그대로 꿰뚫어 봄
- **사마타 ↔ 위빠사나** — 고요(집중)와 통찰. 수레의 두 바퀴. 청정도론의 구분
- **아나빠나사띠와의 관계** — 16단계 1~2테트라드는 사마타적, 3~4테트라드에서 위빠사나로 넘어간다. **아나빠나사띠는 위빠사나로 들어가는 문**
- **삼법인** — 무상(anicca) · 고(dukkha) · 무아(anattā). 관찰이 향하는 곳
- **명칭 붙이기(노팅)** — 공통 기술. "일어남·사라짐", "생각", "소리", "아픔". 실습 중 토글로 라벨 힌트 표시

## 3. 2층 언어 규칙 적용 (PRODUCT_STRATEGY 2-3)

**표면에는 교리 용어를 쓰지 않는다.** 아래 매핑을 데이터에 그대로 넣는다.

| 1층 (큰 글씨 · 입문자) | 2층 (작은 글씨 · 수련생) |
|---|---|
| 있는 그대로 보기 | 위빠사나(觀, vipassanā) |
| 몸에 마음 두기 | 신념처(身念處, kāya) |
| 느낌 알아차리기 | 수념처(受念處, vedanā) |
| 마음 살펴보기 | 심념처(心念處, citta) |
| 열어 두고 지켜보기 | 법념처(法念處, dhamma) |
| 머무는 것은 없다 | 무상(無常, anicca) |
| 이름 붙이기 | 노팅(labeling) |

- **메뉴명은 "위빠사나"가 아니라 "관찰 수행"** 을 우선 검토. (단, 위빠사나는 국내에서 비교적 널리 알려진 편이라 최종 판단은 구현 시점에)
- **실습 화면에는 교리 문구를 넣지 않는다.** 유래·경전은 상세 화면의 접히는 섹션에.

## 4. 실습 4모드 × 6종

요가의 `paced/alternate/pulsed`(조절)와 완전히 다른 **관찰용 4모드**를 신설한다.

| 모드 | 작동 방식 | 시각 연출 |
|---|---|---|
| **guided** | 전체 시간만 카운트, **구간별 안내문이 부드럽게 전환**. 호흡 리듬 지시 없음 | 느린 자율 맥동 + 파문 |
| **scan** | 신체 부위를 정수리→발 순차 이동, 부위당 시간 배분. 위→아래 훑고 되돌아옴 | **인체 실루엣 SVG에 현재 부위 하이라이트가 내려감** |
| **walking** | 들림·나아감·놓음 **3박자**, 좌/우 발 교대, 속도 3단계(3초/2초/1.5초) | 발자국 인디케이터 좌우 교대 |
| **open** | 대상 지정 없음. 화면 거의 비움. 2/3/5분 간격 **은은한 종소리**만 | 잔잔한 파문만 |

### 4-1. 실습 목록

| # | 1층 이름 | 2층 | 단계 | 모드 | 난이도 | goals 태그 |
|---|---|---|---|---|---|---|
| 1 | 숨의 일어남과 사라짐 | 아나빠나 위빠사나 | 2 | guided | 입문 | 불안, 집중 |
| 2 | 몸 훑기 | 바디스캔 · 신념처 | 2 | scan | 입문 | **수면**, 스트레스 |
| 3 | 걸으며 알아차리기 | 경행(經行) | 2 | walking | 입문 | 집중, 스트레스 |
| 4 | 좋음·싫음 알아차리기 | 수념처 | 3 | guided | 중급 | 불안 |
| 5 | 마음 살펴보기 | 심념처 | 4 | guided | 중급 | 불안, 스트레스 |
| 6 | 열어 두고 지켜보기 | 법념처 · 열린 알아차림 | 5 | open | 고급 | — |

### 4-2. guided 안내문 예시 (실습 1 · 10분)

호흡을 **조절하지 않고 관찰만** 하도록 문구를 통제한다. "들이쉬세요" 같은 명령형 금지.

```
0:00–1:30  자세를 잡고, 바닥에 닿은 몸의 무게를 느껴봅니다
1:30–4:00  숨이 들어오고 나가는 것을 그저 지켜봅니다. 고치려 하지 마세요
4:00–7:00  배가 일어나고 사라지는 움직임에 마음을 둡니다
7:00–9:00  생각이 떠오르면 '생각'이라 이름 붙이고, 다시 배로 돌아옵니다
9:00–10:00 지금 이 순간의 몸 전체를 한 번에 느껴봅니다
```

- 구간 전환 시 은은한 종소리(선택 토글)
- 노팅 힌트 카드(토글): `생각 · 소리 · 아픔 · 가려움 · 들뜸 · 졸림`

## 5. 데이터 구조 — ARCHITECTURE의 attitudes 키를 따른다

MBSR이 나중에 같은 실습을 `accept` 태도로 재사용할 수 있도록 **처음부터 이 모양으로 쓴다.** 추가 비용 0으로 미래를 대비하는 부분이다.

```js
// src/data/vipassana.js (이관 후 → src/practices/body-scan.js)
{
  id: 'body-scan',
  object: 'body',
  engine: 'scan',
  level: 2,
  goals: ['sleep', 'stress'],
  segments: ['정수리','이마','눈·얼굴','턱','목','어깨','팔','손',
             '가슴','배','등','허리','엉덩이','허벅지','무릎','종아리','발목','발바닥'],
  supports: ['observe', 'accept'],

  attitudes: {
    observe: {                               // 위빠사나
      title: '몸 훑기',  context: '신념처(kāya)',
      cue: '감각이 일어나고 사라지는 것을 봅니다',
      closing: '모든 감각은 머물지 않습니다',
    },
    accept: {                                // MBSR (추후, 키만 추가하면 됨)
      title: '바디스캔',  context: '1–2주차',
      cue: '좋다 나쁘다 판단하지 말고, 있는 그대로 알아차립니다',
      closing: '지금 이 순간으로 돌아옵니다',
    },
  },
}
```

## 8. 안전 안내 (필수)

위빠사나는 다른 명상보다 **억눌린 감정·기억이 올라올 수 있는** 수행이다. 이 점을 반드시 넣는다.

- 힘들면 **즉시 멈추고 눈을 뜨고 발바닥 감각으로 돌아오기**
- 정신건강에 어려움이 있다면 **전문가와 상담 후** 시작
- **의료 효과는 단정하지 않는다** ("불안이 낫습니다" 금지 / "많은 분들이 도움을 받습니다" 수준)
- 1단계 개념 카드와 각 실습 상세에 배치. 고급 실습(열린 알아차림)은 시작 전 확인 모달

> 요가의 `pulsed` 금기 동의 모달과 같은 패턴을 재사용한다.
