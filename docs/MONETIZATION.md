# 수익화 기획 — 숨결의 길 (구독제 전용)

> **모델:** 광고 없는 프리미엄(Freemium) 구독제
> **작성일:** 2026-07-24
> **원칙:** 무료로 습관을 만들고, 프리미엄으로 깊이·편의·감정적 보상을 제공한다. 가르침(교리)은 열고, 수행 경험 강화 요소를 유료화한다.

## 1. 무료 vs 프리미엄 기능 분리

| 기능 | 무료 (Free) | 프리미엄 (Premium) |

| **배경음(앰비언트)** | 파도 1종 | 라이브러리(빗소리·숲·새소리·계곡·싱잉볼세트) + 믹스 |

| **통계** | 총 횟수·시간 기본 | 추세·인사이트·연속기록 챌린지 |

## 3. 페이월(Paywall) 전략 — "부드럽게"

명상 앱은 강압적 페이월이 브랜드를 해침. **소프트 페이월**로.

1. **첫날은 막지 않는다** — 온보딩 → 첫 호흡 세션 완주 경험(무료)으로 가치 먼저 체감
2. **잠긴 기능을 만졌을 때** 자연스럽게 안내:
   - 잠긴 호흡 패턴/배경음 탭 → "프리미엄에서 열려요" + 미리듣기
   - 8번째 일지 저장 시도 → "무제한 기록은 프리미엄"
   - 심화 단계(제3·4념처) 음성 명상 → 페이월
3. **7일 무료 체험**을 페이월 CTA로 (부담 최소화)
4. **연간 플랜을 기본 선택**으로 강조, 월간은 보조

## 4. 구현 매핑 (현재 코드 기준)

현재 앱에 붙일 요소:

- **엔타이틀먼트 판별:** `useEntitlement()` 훅 (RevenueCat SDK → `isPremium` 반환). 웹/개발 중엔 Supabase `profiles.is_premium` 플래그로 임시 대체 가능.
- **게이팅 헬퍼:** `PATTERNS`/앰비언트 목록에 `premium: true` 플래그 추가 → 무료 유저에겐 자물쇠 배지 + 탭 시 페이월.
- **Paywall 컴포넌트:** 플랜 카드(월/연/평생) + 7일 체험 CTA + 혜택 목록.
- **일지 제한:** 무료는 `list()` 결과를 최근 7일만 노출 + "더 보려면 프리미엄" 안내.
- **음성 명상:** Supabase Storage에 오디오 업로드 → 프리미엄만 재생 URL 접근(RLS/서명URL).

> 웹 버전(GitHub Pages)에서는 결제가 불가하므로, **결제·프리미엄은 앱(Capacitor+RevenueCat)에서** 동작. 웹은 미리보기/체험 채널로 유지.
